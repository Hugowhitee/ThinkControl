# ThinkControl exact asset pack v3

Canonical brand source imported from the approved `ThinkControl_TC_Exact_Asset_Pack_v3` package.

The TC geometry is vector-traced from the approved reference. Do not redraw, simplify or replace the C/dot geometry with a generated approximation.

- `master/` contains the exact TC mark and app-dark source.
- `wordmark/` contains the exact outlined ThinkControl wordmarks used by GitHub and the WPF brand control.
- `status/` contains exact state-mark SVG variants.
- `windows/` contains the multi-resolution Windows ICO sources, including state variants.

The application copies the exact Windows icons into `src/ThinkControl.UI/Assets/`; the README wordmarks in `docs/assets/` are exact copies of the corresponding source assets.
