# ThinkControl v0.1.0-alpha.4

Alpha.4 is the first test release after the consolidated cooling/power/audio work and the Windows UI consistency pass.

## Included

- Stable left-aligned Advanced page rail across normal, minimum and wide layouts.
- Dark themed scrollbars and unified window/sidebar surfaces.
- Correct compact/full directional controls: compact opens up-left, Advanced returns down-right.
- Canonical ThinkControl icon across taskbar, Notification Area and installer shortcuts.
- Improved Touchpad gesture visual with real edge-width bands and subtle 4 px touchpad corners.
- Immediate generic Precision Touchpad haptic capability detection.
- Supervised Lenovo cooling profiles, fan telemetry and characterization safeguards.
- Separate battery/plugged-in power preferences, Sensors and Dolby Audio pages.
- Reordered navigation: Home, Performance, Fans, Sensors, Battery, Display, Audio, Keyboard, Touchpad, System, Updates, Settings.
- Compact Fan noise control for Auto, Silent, Normal and Cool profiles.

## Validation gate

The release is published only after the exact main commit passes build, tests, expanded WPF visual QA and the full bootstrap installer/service/uninstall smoke test.
