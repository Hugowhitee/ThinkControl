# ThinkControl screenshots

This folder is reserved for screenshots of the **running application**.

Do not commit early concept art or generated mockups here as if they were runtime captures. The first snapshot set is added after the current alpha UI is rendered and checked on Windows.

Expected files:

- `compact-dark.png`
- `compact-light.png`
- `advanced-home.png`
- `advanced-fans.png`
- `advanced-keyboard.png`
- `advanced-battery.png`
- `installer-finish.png`

When a screenshot changes materially, replace the file rather than accumulating versioned image clutter. Release-specific historical screenshots belong in GitHub Releases, not in this folder.
