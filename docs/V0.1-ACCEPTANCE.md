# v0.1 acceptance criteria

The first ThinkControl release has two separate milestones.

1. Downloadable alpha: the package builds, installs, starts its service, uninstalls cleanly and is clearly identified as a prerelease.
2. X9-validated alpha: the published package has also passed the physical ThinkPad X9-15 Gen 1 hardware and UI validation pass.

Publishing an alpha asset does not by itself prove every hardware capability on the reference device.

## Downloadable alpha

### Build and packaging

- [x] .NET 10 solution builds in Release on Windows CI.
- [x] CI renders the real compact and Advanced WPF surfaces.
- [x] The package contains the x64 UI and hardware service.
- [x] UI and service are framework-dependent so the .NET runtime is not duplicated in the payload.
- [x] Setup detects the required .NET 10 Desktop Runtime and can acquire a pinned verified Microsoft runtime when it is absent.
- [x] Setup can acquire pinned verified PawnIO 2.2.0 on the X9 reference profile without making it a requirement for unrelated features.
- [x] Package workflow enforces payload and installer size budgets.
- [x] Silent install completes successfully in package validation.
- [x] `ThinkControlService` reaches `Running`.
- [x] Silent uninstall removes service registration and application files.
- [x] A SHA-256 checksum is generated.
- [x] App, installer and release workflows use the same version source.
- [x] Release-ready builds can create the exact `v<version>` tag.

### User interface

- [x] Compact tray window and resizable Advanced window are implemented.
- [x] Compact is a fixed tray flyout rather than a draggable desktop window.
- [x] Advanced uses the native Windows title bar, taskbar presence, maximize/restore behavior and Snap Layouts.
- [x] System, Light and Dark themes are implemented.
- [x] Main layout is declared in XAML and can be edited with Visual Studio or Blend.
- [x] Functional icons use the local icon set and ThinkControl branding uses the approved v3 asset geometry.
- [x] The UI does not display fabricated dBA, wattage targets or fan percentages.
- [x] Fan state appears with real RPM when available.
- [x] Refresh rate, brightness and adaptive brightness are grouped under Display.
- [x] Battery telemetry can show live power, Wh, health and filtered time estimates when available.
- [x] Keyboard hardware levels are separated from user-session effects.
- [x] Compatibility diagnostics appear once in Settings.
- [x] CI snapshots are checked for obvious clipping and layout regressions.

### Hardware safety

- [x] The UI runs as a normal user.
- [x] Privileged hardware access is isolated in `ThinkControl.Service`.
- [x] IPC is versioned and semantic.
- [x] No generic EC, port or IOCTL passthrough is exposed to the UI.
- [x] X9 machine types `21Q6` and `21Q7` are identified without serial-number matching.
- [x] Lenovo SKU parsing prioritizes the verified machine type instead of accepting unrelated four-character text first.
- [x] The X9 fan backend uses control register `0x2F` and tachometer registers `0x84/0x85`.
- [x] Lenovo Auto is `0x80` and manual levels are limited to `1` through `7`.
- [x] Fan-off `0x00` and the unverified `0x40` family are blocked.
- [x] Normal shutdown attempts to return manual fan control to Lenovo Auto.
- [x] RPM polling is conservative.
- [x] Lenovo keyboard writes use readback verification.
- [x] Installed Lenovo Vantage ThinkKeyboard components can be used only as a validated fallback.
- [x] Unknown devices do not inherit X9 EC writes.

### Diagnostics and device support

- [x] Unvalidated devices use the same main product areas rather than a separate reduced edition.
- [x] Device documentation distinguishes verified, beta and generic support.
- [x] Diagnostics use bounded local storage and an allowlisted schema.
- [x] Unique identifiers, typed text and audio samples are excluded from diagnostics.
- [x] The public bug report form accepts exact model information and optional attachments.
- [x] Network diagnostics upload remains disabled until a private endpoint exists.

### Distribution and branding

- [x] The approved ThinkControl v3 master geometry is retained in the repository.
- [x] The executable, tray, installer and README use exports from the approved asset pack rather than recreated glyphs.
- [x] Commercial Vantage opens the installed app when available; the Store is only a fallback.
- [x] The update checker reports a friendly no-release/unavailable state instead of exposing a raw GitHub 404.

## X9 validation of the published package

Use the published installer rather than a loose development build.

- [ ] Install `ThinkControl-Setup-0.1.0-alpha.1.exe` on the physical X9.
- [ ] Confirm the bootstrap installer is substantially smaller than the old self-contained package.
- [ ] Confirm `.NET 10 Desktop Runtime` detection does not redownload an already installed compatible runtime.
- [ ] Confirm PawnIO detection/install behavior on the X9.
- [ ] Confirm `ThinkControlService` starts normally.
- [ ] Confirm the app identifies machine type `21Q6` / `21Q7` as the verified X9 profile rather than Beta/Untested.
- [ ] Confirm CPU temperature and source label.
- [ ] Confirm fan RPM remains stable with conservative polling.
- [ ] Confirm Lenovo Auto.
- [ ] Confirm manual fan levels 1 through 7 and that the fan response is observable where firmware permits it.
- [ ] Confirm normal app/service stop and uninstall release manual fan control safely.
- [ ] Confirm keyboard Off, Low and High using the available Lenovo provider/fallback.
- [ ] Tune and confirm Breathing against the physical keyboard transition.
- [ ] Confirm Auto and Reactive keyboard behavior.
- [ ] Confirm Commercial Vantage opens the installed application directly.
- [ ] Test sleep and resume.
- [ ] Inspect Compact and Advanced at 100, 125 and 150 percent Windows scaling.
- [ ] Confirm Compact stays anchored and cannot be dragged away.
- [ ] Confirm the native Advanced title bar has the correct ThinkControl icon and standard Windows controls.
- [ ] Fix any issue that only appears in the published package.

After this pass, the relevant X9 capability claims can be promoted to physically validated for that release.

## Work after the first alpha

- validation on additional Lenovo models;
- private opt-in diagnostics submission;
- touchpad gesture and haptic controls;
- autonomous fan curves with lifecycle and recovery safeguards;
- further accessibility and real-device scaling validation;
- Authenticode signing when a suitable code-signing path is available.
