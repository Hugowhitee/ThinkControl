# v0.1 acceptance criteria

The first ThinkControl release has two separate milestones.

1. Downloadable alpha: the package builds, installs, starts its service, uninstalls cleanly and is clearly identified as a prerelease.
2. X9-validated alpha: the published package has also passed the physical ThinkPad X9-15 Gen 1 hardware and UI validation pass.

Publishing an alpha asset does not by itself prove every hardware capability on the reference device.

## Downloadable alpha

### Build and packaging

- [x] .NET 10 solution builds in Release on Windows CI.
- [x] CI renders the real Compact and Advanced WPF surfaces.
- [x] UI and service are framework-dependent so .NET is not duplicated in both payloads.
- [x] Release packaging creates a separate `ThinkControl-Payload-<version>.zip`.
- [x] Setup embeds the exact payload URL and SHA-256 instead of embedding the application payload.
- [x] Package CI enforces a 5 MB hard ceiling on the web bootstrap installer.
- [x] Setup detects/acquires a pinned Microsoft .NET 10 Desktop Runtime only when missing.
- [x] Setup offers pinned PawnIO 2.2.0 only on the verified X9 reference profile.
- [x] Package CI smoke-tests the same payload hash through a local validation override.
- [x] `ThinkControlService` reaches `Running` after bootstrap extraction/registration.
- [x] Silent uninstall removes service registration and extracted UI/service files.
- [x] SHA-256 checksums are generated for installer and payload.
- [x] App, installer and release workflows use the same version source.
- [x] Release-ready builds can create the exact `v<version>` tag.
- [x] Release publication verifies installer, payload and checksum assets before recording success.

### User interface

- [x] Compact tray window and resizable Advanced window are implemented.
- [x] Compact is a fixed tray flyout rather than a draggable desktop window.
- [x] Compact uses one diagonal `↖` action to open Advanced.
- [x] Advanced uses the native Windows title bar, taskbar presence, standard maximize/restore behavior and Snap Layouts.
- [x] Advanced uses a matching `↘` action to return to Compact.
- [x] System, Light and Dark themes are implemented.
- [x] Main layout is declared in XAML and can be edited with Visual Studio or Blend.
- [x] Compatibility diagnostics appear exactly once in Settings.
- [x] The UI does not display fabricated dBA, wattage targets or fake fan percentages.
- [x] Fan state appears with real RPM when available.
- [x] Battery telemetry can show live power, Wh, health and filtered time estimates when available.
- [x] Keyboard hardware levels are separated from user-session effects.

### Branding

- [x] `assets/brand/v3` is the canonical source.
- [x] Application/installer ICO exactly matches the v3 Windows source.
- [x] Tray ICO exactly matches the v3 mark source.
- [x] README dark/light wordmarks exactly match the v3 outlined source assets.
- [x] WPF `BrandMark` uses the exact traced 1536×1536 v3 master geometry.
- [x] Legacy hand-drawn 64×64 TC geometry is removed from the app.
- [x] Unused legacy app branding asset is removed.
- [x] Packaging CI fails if branding drifts or legacy TC geometry reappears.

### Hardware safety

- [x] The UI runs as a normal user.
- [x] Privileged hardware access is isolated in `ThinkControl.Service`.
- [x] IPC is versioned and semantic.
- [x] No generic EC, port or IOCTL passthrough is exposed to the UI.
- [x] X9 machine types `21Q6` and `21Q7` are identified without serial-number matching.
- [x] Lenovo SKU parsing prioritizes the verified machine type instead of accepting unrelated four-character text first.
- [x] The X9 fan backend uses control register `0x2F` and tachometer registers `0x84/0x85`.
- [x] Lenovo Auto is `0x80` and manual levels are limited to `1` through `7`.
- [x] Fan-off `0x00` and the unverified `0x40` family are blocked.
- [x] Normal shutdown attempts to return manual fan control to Lenovo Auto.
- [x] RPM polling is conservative.
- [x] Lenovo keyboard writes use readback verification.
- [x] Installed Lenovo Vantage ThinkKeyboard components can be used only as a validated fallback.
- [x] Unknown devices do not inherit X9 EC or X9 Intelligent Cooling writes.

### X9 thermal policy

- [x] Quiet/Balanced/Performance still use Windows power mode as the primary supported surface.
- [x] On verified X9 only, successful Windows mode changes asynchronously coordinate Lenovo Intelligent Cooling.
- [x] AC commands are limited to 502/503/504.
- [x] DC commands are limited to 507/508/509.
- [x] The LITSSvc pipe call uses the observed UInt32 request / Int32 response contract.
- [x] Lenovo response-value semantics are not guessed; a complete response is the protocol readback boundary.
- [x] Lenovo thermal policy is documented separately from direct fan-RPM control.

### Diagnostics and integration

- [x] Unvalidated devices use the same main product areas rather than a separate reduced edition.
- [x] Diagnostics use bounded local storage and an allowlisted schema.
- [x] Unique identifiers, typed text and audio samples are excluded from diagnostics.
- [x] Commercial Vantage opens the installed app when available instead of always opening Microsoft Store.
- [x] The update checker reports a friendly no-release/unavailable state instead of exposing a raw GitHub 404.

## X9 validation of the published alpha.2 package

Use the published release rather than a loose development build.

- [ ] Install `ThinkControl-Setup-0.1.0-alpha.2.exe` on the physical X9.
- [ ] Confirm the bootstrap installer is only a few MB and downloads `ThinkControl-Payload-0.1.0-alpha.2.zip` from GitHub.
- [ ] Confirm payload SHA-256 verification completes and the installed app footprint is far below the previous duplicate-runtime layout.
- [ ] Confirm .NET detection does not redownload an already installed compatible runtime.
- [ ] Confirm PawnIO detection/install behavior on X9.
- [ ] Confirm `ThinkControlService` starts normally.
- [ ] Confirm the app reports `21Q6`/`21Q7` as verified X9 rather than Beta/Untested.
- [ ] Confirm CPU temperature and source label.
- [ ] Confirm fan RPM remains stable with conservative polling.
- [ ] Confirm Lenovo Auto and manual fan levels 1 through 7.
- [ ] Confirm normal app/service stop and uninstall release manual fan control safely.
- [ ] Compare Quiet/Balanced/Performance behavior and confirm Lenovo Intelligent Cooling receives the matching AC/DC policy on the X9.
- [ ] Confirm keyboard Off, Low and High using the available Lenovo provider/fallback.
- [ ] Tune and confirm Breathing against the physical keyboard transition.
- [ ] Confirm Auto and Reactive keyboard behavior.
- [ ] Confirm Commercial Vantage opens the installed application directly.
- [ ] Confirm update checking no longer displays a raw 404.
- [ ] Test sleep and resume.
- [ ] Inspect Compact and Advanced at 100, 125 and 150 percent Windows scaling.
- [ ] Confirm Compact stays anchored and cannot be dragged away.
- [ ] Confirm Advanced uses the correct v3 title-bar/taskbar icon and native Windows controls.

## Work after the first alpha

- validation on additional Lenovo models;
- private opt-in diagnostics submission;
- touchpad gesture and haptic controls;
- autonomous fan curves with lifecycle and recovery safeguards;
- further accessibility and real-device scaling validation;
- Authenticode signing when a suitable code-signing path is available.
