# Alpha release checklist

This checklist defines the bar for publishing the first downloadable ThinkControl alpha. It describes the current codebase rather than an earlier foundation milestone.

## Build and packaging

- [x] .NET 10 solution restores and builds in Release on `windows-latest`.
- [x] CI renders the real WPF compact and Advanced surfaces to PNG for visual regression review.
- [x] Package workflow publishes the x64 UI and hardware service into one installer.
- [x] Installer smoke test performs silent install, verifies `ThinkControlService` reaches `Running`, uninstalls, and verifies the service/files are removed.
- [x] Installer output includes a SHA-256 checksum.
- [x] Application, installer and release workflow use the same product version source.
- [ ] Publish the first tagged GitHub prerelease and attach the installer/checksum.

## User interface

- [x] Compact tray popup and resizable Advanced window are implemented.
- [x] System, dark and light themes are implemented.
- [x] Main visual layout is declarative XAML and can be edited with Visual Studio/Blend.
- [x] General UI icons use one Material Symbols Outlined-based vector set.
- [x] Compact UI contains no fabricated dB, wattage or fan-percentage values.
- [x] Fan state/level is shown next to real RPM telemetry when available.
- [x] Display refresh, brightness and adaptive brightness form one coherent section.
- [x] Battery UI exposes live W, Wh/health where available and a smoothed ETA.
- [x] Keyboard hardware levels are separated from ThinkControl Auto/Breathing/Reactive/Audio policies.
- [x] Compatibility diagnostics are visible in Settings.
- [ ] Complete a final on-device visual pass at 100%, 125% and 150% scaling on the X9 reference machine.

## Hardware and safety

- [x] UI runs as a normal user; privileged hardware access is isolated in `ThinkControl.Service`.
- [x] IPC is versioned and semantic; no raw EC/port/IOCTL passthrough is exposed to the UI.
- [x] X9 machine types 21Q6/21Q7 are explicitly identified without serial-number matching.
- [x] X9 fan backend uses the validated control register `0x2F`, tachometer registers `0x84/0x85`, Lenovo Auto `0x80`, and manual levels `1`–`7`.
- [x] Fan-off `0x00` and unverified `0x40` override writes are blocked.
- [x] Manual fan ownership attempts to return to Lenovo Auto when the service/controller is disposed.
- [x] RPM reads are deliberately sparse to avoid the cadence observed with frequent EC polling.
- [x] Keyboard writes use only the retained Lenovo PM backend and require read-back verification.
- [x] The research-only `EnergyDrv` keyboard path is not part of the production backend.
- [x] Unknown devices do not inherit X9 EC writes.
- [ ] Validate RPM, levels 1–7, Lenovo Auto restoration and keyboard Off/Low/High on the physical X9 with the packaged installer.
- [ ] Validate sleep/resume behavior while ThinkControl is installed and while manual fan control has been used.

## Device support and diagnostics

- [x] UI distinguishes Verified, Experimental and Not validated compatibility states.
- [x] Unvalidated devices retain the same product areas instead of receiving a separate stripped-down UI.
- [x] Diagnostics use an allowlisted semantic event schema and bounded local storage.
- [x] Serial numbers, usernames, hostnames, MAC addresses, disk serials, typed text and audio samples are excluded from compatibility diagnostics.
- [x] Public GitHub bug-report form supports device-family selection, exact free-form model name and optional attachments.
- [ ] Configure the private diagnostics submission endpoint before enabling network upload.

## Installation dependencies

- [x] ThinkControl UI and service are installed/removed by the ThinkControl installer.
- [x] Current alpha package is self-contained; users do not need to install the .NET SDK/runtime manually.
- [x] Lenovo/Intel OEM components remain vendor-owned and are not mirrored blindly by ThinkControl.
- [ ] Add the verified PawnIO prerequisite flow to the installer so a clean X9 installation can enable EC fan telemetry/control without manual setup.
- [ ] Pin and verify the accepted PawnIO package/version/checksum before enabling automatic installation.

## Documentation

- [x] README identifies the product, current version, supported-device status, install path, releases page and bug-report path.
- [x] Product, design, device-support, diagnostics and UI-editing docs describe the current product rather than the history of development requests.
- [x] Hardware research remains separate from user-facing support claims.
- [x] Third-party Material Symbols attribution/license is documented.

## First public alpha blockers

The first public alpha is ready to tag after these items are completed:

1. run the packaged installer on the physical ThinkPad X9-15 Gen 1;
2. verify CPU temperature, fan RPM, fan levels 1–7 and Lenovo Auto recovery;
3. verify keyboard Off/Low/High and the software effects that build on those levels;
4. check compact and Advanced UI at common Windows scaling levels;
5. decide whether PawnIO is bundled into this alpha installer or clearly required as a temporary prerequisite;
6. publish `ThinkControl v0.1.0-alpha.1` as a GitHub prerelease with installer and SHA-256 asset.
