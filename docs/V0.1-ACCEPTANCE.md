# Alpha release checklist

This checklist separates two milestones that must not be confused:

1. **Downloadable alpha prerelease** — the package builds, installs, starts its service, uninstalls cleanly and is clearly labelled alpha.
2. **Reference-device validated alpha** — the exact packaged prerelease has also passed the physical ThinkPad X9-15 Gen 1 hardware/UI test pass.

Publishing the prerelease makes it possible to test the exact release asset on the reference machine; it does not by itself mark the hardware backend Verified for stable use.

## Downloadable alpha gates

### Build and packaging

- [x] .NET 10 solution restores and builds in Release on Windows CI.
- [x] CI renders the real WPF compact and Advanced surfaces to PNG for visual regression review.
- [x] Package workflow publishes the x64 UI and hardware service into one installer.
- [x] Installer smoke test performs silent install, verifies `ThinkControlService` reaches `Running`, uninstalls, and verifies the service/files are removed.
- [x] Installer output includes a SHA-256 checksum.
- [x] Application, installer and release workflow use the same source version.
- [x] Release-ready main builds can create the exact `v<version>` tag.
- [ ] Confirm the first tagged GitHub prerelease and installer/checksum are visible after the release-candidate merge.

### User interface

- [x] Compact tray popup and resizable Advanced window are implemented.
- [x] System, dark and light themes are implemented.
- [x] Main visual layout is declarative XAML and can be edited with Visual Studio/Blend.
- [x] General UI icons use Material Symbols Outlined-based local vector geometry.
- [x] Compact UI contains no fabricated dB, wattage or fan-percentage values.
- [x] Fan state/level is shown next to real RPM telemetry when available.
- [x] Display refresh, brightness and adaptive brightness form one coherent section.
- [x] Battery UI exposes live W, Wh/health where available and a smoothed ETA.
- [x] Keyboard hardware levels are separated from ThinkControl Auto/Breathing/Reactive/Audio policies.
- [x] Compatibility diagnostics are visible in Settings.
- [x] Dark/light CI snapshots have been visually reviewed for clipping/layout regressions.

### Hardware safety implemented before distribution

- [x] UI runs as a normal user; privileged hardware access is isolated in `ThinkControl.Service`.
- [x] IPC is versioned and semantic; no raw EC/port/IOCTL passthrough is exposed to the UI.
- [x] X9 machine types 21Q6/21Q7 are explicitly identified without serial-number matching.
- [x] X9 fan backend uses control register `0x2F`, tachometer `0x84/0x85`, Lenovo Auto `0x80`, and levels `1–7`.
- [x] Fan-off `0x00` and unverified `0x40` override writes are blocked.
- [x] Manual fan ownership attempts to return to Lenovo Auto on normal controller/service disposal.
- [x] RPM reads are deliberately sparse.
- [x] Keyboard writes use the retained Lenovo PM backend with read-back verification.
- [x] Research-only `EnergyDrv` keyboard paths are not part of the production backend.
- [x] Unknown devices do not inherit X9 EC writes.

### Device support / diagnostics

- [x] Unvalidated devices retain the same main product areas rather than a separate stripped-down edition.
- [x] Documentation states that unknown ThinkPads do not yet receive writable Experimental fan/keyboard providers in alpha.1.
- [x] Diagnostics use allowlisted semantic events and bounded local storage.
- [x] Unique/private identifiers, typed text and audio samples are excluded.
- [x] Public bug-report form supports device family, free-form exact model and optional attachments.
- [x] Network diagnostics upload remains disabled until a private project endpoint exists.

### Installation dependencies

- [x] ThinkControl UI/service are installed and removed by ThinkControl Setup.
- [x] Alpha package is self-contained; no manual .NET runtime/SDK install is required.
- [x] Lenovo/Intel OEM components remain vendor-owned.
- [x] README/installer docs clearly state that PawnIO prerequisite installation is not automated in alpha.1.

## Reference-device validation after downloading the prerelease

Use the **published installer**, not a loose development executable, for this pass.

- [ ] Install `ThinkControl-Setup-0.1.0-alpha.1.exe` on the physical X9.
- [ ] Confirm `ThinkControlService` starts normally.
- [ ] Confirm CPU temperature and exact sensor/source label.
- [ ] Confirm fan RPM appears and remains acoustically stable with conservative polling.
- [ ] Confirm Lenovo Auto.
- [ ] Confirm manual levels `1`–`7` individually.
- [ ] Confirm normal app/service stop and uninstall return direct fan ownership safely.
- [ ] Confirm keyboard Off / Low / High.
- [ ] Tune/confirm Breathing against Lenovo's real level-transition fade.
- [ ] Confirm Auto and Reactive keyboard policies.
- [ ] Test sleep/resume.
- [ ] Inspect installed Compact + Advanced UI at 100%, 125% and 150% Windows scaling.
- [ ] File/fix any release-asset-specific issue found during the pass.

Once these pass, the X9 capability claims can be promoted from “implemented / alpha validation” to **physically validated for that release**.

## Post-alpha work

These are not blockers for making the prerelease downloadable, but they remain important before a mature/stable release:

- installer-managed pinned PawnIO prerequisite;
- additional ThinkPad provider validation;
- private opt-in diagnostics submission endpoint;
- autonomous custom fan-curve engine;
- conflict arbitration and stronger ungraceful-crash recovery;
- further accessibility/UI polishing and real-device scaling evidence.
